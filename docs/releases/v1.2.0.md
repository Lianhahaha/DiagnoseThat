# Pulse v1.2.0 — Midnight

Pulse v1.2.0 is a complete visual redesign. The new **Midnight** identity makes Windows activity easier to read at a glance: plain language first, technical detail one click away.

Design decision: [ADR-012](../architecture/decisions/ADR-012-midnight-visual-identity.md).

## What's New

### Midnight design

- Near-black canvas, flat panels and hairline borders
- Lime signature accent for live state, selection and primary actions
- Bundled Geist and Geist Mono fonts (SIL Open Font License, no runtime download)
- Information severity is blue, so the accent never reads as an event level
- Light mode updated with neutral surfaces and a darkened accent for contrast

### Shell

- Slim icon rail replaces the sidebar; Assistant and Settings sit at the bottom
- PulseService status dot in the rail footer
- Command search moves into a pill in the title bar (Ctrl+K)

### Timeline

- Plain-language summary of the last hour, with event, error and warning counts
- 24-hour activity strip in 30-minute slices, colored by the worst severity
- Story-feed rows: local time, severity node, human sentence first, technical hints after
- Event inspector with **Explained / Technical / Raw XML** tabs (the AGENTS.md information hierarchy); raw XML loads when the tab opens

### System Health

- Overview bento: system pulse tile with health score, uptime and a 0–100 % CPU chart
- Live tiles for memory (ring), CPU, GPU (with temperature) and network
- Utilization colors and charts on the Midnight palette

### Reports, Assistant and controls

- Floating export summary panel in Reports
- Assistant: side-by-side provider and model pickers, suggestion pills, inverted user bubbles, pill composer
- Pill segmented controls and flat form fields across the app

### Fixes

- System Health showed "Windows 10" on Windows 11 machines (the registry `ProductName` is never updated by Windows); builds 22000 and later now report Windows 11
- Assistant send icon was white on the accent fill and hard to read
- Search field drew a doubled border
- PulseService is registered with a quoted image path (fixes the unquoted service path under `C:\Program Files` and the false "Paths match: No" in Diagnose)
- Diagnose reported build version 1.1.0 for the new service
- Microsoft Store package embeds the full PulseMCP payload for AI Integration

## Upgrade notes

- The accent preference starts on the new lime accent once after upgrading; choose another under **Settings → Appearance**
- Confirm **Diagnose → Service** shows **1.2.0** after installing
- If you use MCP: **Settings → AI Integration → Unregister → Register**
