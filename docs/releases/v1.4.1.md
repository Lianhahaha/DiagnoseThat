# Pulse v1.4.1 — Every disk, every wake

Pulse v1.4.1 is built from what users asked for after 1.4: health for every disk, what woke the PC, plain-language Secure Boot events and a deeper, safer Assistant.

## Highlights

- **Health for every disk.** *System Health → Storage → SMART* now shows one block per physical disk: model, bus, health and temperature, and for NVMe drives also wear, spare capacity, power-on time, unsafe shutdowns, media errors and data read / written. NVMe critical warnings are spelled out, for example *spare capacity is below its threshold* ([#20](https://github.com/Regncreative/Pulse/issues/20), [#12](https://github.com/Regncreative/Pulse/issues/12)).
- **What woke the PC.** The wake event now names the cause:
  - *PC woke up: Intel(R) Ethernet Connection I219-V*, with where to stop a device from waking the PC
  - *PC woke up for a scheduled task*, naming the task and the program, with where to turn off wake timers
- **Secure Boot events, explained.** The TPM-WMI Secure Boot update events, several logged as errors, get plain titles that follow Microsoft's documentation. Applied updates are marked as routine. The SBAT update failure (1796) says Windows tries again at the next restart. Firmware and BitLocker cases say what to do ([#25](https://github.com/Regncreative/Pulse/issues/25)).
- **Deeper Assistant diagnostics** ([#17](https://github.com/Regncreative/Pulse/issues/17)):
  - Process details include the command line, elevation, architecture, start time and total CPU time
  - Processes can be ranked by private bytes, which shows a leak better than the working set
  - A new read-only *Windows services* tool answers questions like "is Windows Search running?"
- **Assistant connection settings** ([#21](https://github.com/Regncreative/Pulse/issues/21)). *Settings → Privacy → Assistant* sets the Ollama and LM Studio ports and an optional LM Studio API key, which is kept in Windows Credential Manager. *Local AI not found* now says where Pulse looked, for example *LM Studio server is not running on 127.0.0.1:1234. Start it in LM Studio → Developer.*

## Fixes

- **Disk temperature and SMART data were missing.** PulseService opened disks with read access, which its LocalService account does not have. Disk health is now read without it and refreshed every 5 minutes.
- **Assistant replies from Ollama repeated themselves** ("HelloHello!Hello! I…"). This had been in every release since 1.1. LM Studio could also drop text split across network packets.
- **The Assistant kept showing "Connected"** after Ollama or LM Studio was closed. A failed message now re-checks the runtime.

## Security

The Assistant talks only to a local AI on this PC, and there is no setting to change that:

- Only `127.0.0.1` and `::1` are accepted. `localhost` is refused, because the hosts file can point it at another machine.
- Redirects are never followed, and system or environment proxies are ignored.
- The settings have a port field but no address field, so other computers and cloud services cannot be set.

## Upgrade notes

- Confirm **Diagnose → Service** shows **1.4.1** after installing.
- If you changed the Ollama or LM Studio port, set it in *Settings → Privacy → Assistant*. The defaults are 11434 and 1234.
