# Pulse v1.5.0 — Every GPU, quieter Timeline

Two long-standing requests: System Health for PCs with more than one GPU ([#9](https://github.com/Regncreative/Pulse/issues/9)), and a way to quiet events you already know about ([#25](https://github.com/Regncreative/Pulse/issues/25)).

## New

- **Every GPU in System Health** ([#9](https://github.com/Regncreative/Pulse/issues/9)). On a PC with an integrated and a dedicated GPU, the GPU panel lists both under *All GPUs*, each with its load and its dedicated and shared memory, and marks the GPU the rest of the panel describes. The Assistant's GPU tool and health reports include the list. A PC with one GPU looks the same as before. Software adapters (Microsoft Basic Render Driver) are left out.
- **Hide events you expect** ([#25](https://github.com/Regncreative/Pulse/issues/25)). In an event's details, *Hide events like this* hides every event with the same provider and Event ID from the Timeline and its error and warning counts. A *hidden events* counter in the filter bar shows them again on demand, and Settings → Timeline → Hidden events lists each hidden type with *Show again*. Nothing is hidden by default. Only Pulse's view changes: Windows' logs are untouched, and reports and exports still contain every event. A critical event of a hidden type no longer raises a desktop notification.
- **One Pulse at a time.** Starting Pulse while it already runs, even hidden in the tray, brings that window forward instead of opening a second Pulse with a second tray icon. Starting with Windows never pops the window up.

## Changes

- **GPU load is computed like Task Manager.** Windows reports GPU engine load per process. Task Manager adds the processes on each engine together and shows the busiest engine; Pulse took the busiest single process, so it read low when several programs shared the GPU. Pulse now does what Task Manager does, so GPU load can read higher than in 1.4.

## Feedback wanted

The *All GPUs* list was checked on a PC with one GPU. If your PC has an integrated and a dedicated GPU, a comment on [#9](https://github.com/Regncreative/Pulse/issues/9) comparing Pulse with Task Manager → Performance is welcome.

## Upgrade notes

- Confirm **Diagnose → Service** shows **1.5.0** after installing.
- Hidden event types are stored on this PC only.
